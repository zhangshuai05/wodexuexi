## 1. 项目负责人的最新指令（2026-09-24，最高优先级）

> "拆三道锁还只是一个局部修复，真正的 v13 核心很可能是把 K 选择从几何聚类指标
> 改造成面向最终句子归属的、经过样本外验证的判据。"

### 1.1 三件必补的事

**第一，把主指标正式定义成句子级说话人归属率。** 必须明确五件事：

1. 一句话的时间范围如何取得；
2. 重叠语音怎么计；
3. 短句、极短句、无法对齐的句子怎么处理；
4. 按句子平均，还是按时长加权；
5. 说话人标签置换如何解决。

DER / JER / 簇纯度可作辅助指标，**但最终主表必须直接展示句子归属正确率**。
否则仍可能出现 **DER 下降、目标指标不升**。

**第二，不要让 train_L 三场结果承担过多结论。** 三场只能说明"存在反向机制"，
不能说明该机制已普遍存在。**全量 30 场之后，最好按场次给出**：
baseline / 仅拆门 / 拆门加新 K 判据 / 真实路径最终句子归属率 / 每场的 K、簇大小、回退原因。
**不要只报平均值**，否则会掩盖某些房间或说话人数区间的灾难性失败。

**第三，K 的评分函数必须向下游目标靠拢。** Silhouette 不等价于说话人可分性，
尤其在下列情况会**系统性偏好低 K**：

- 说话人数量较多；
- 各说话人占比接近；
- Embedding 类内分散；
- 高 K 产生碎簇；
- 后续细化会重新传播锚点标签。

**K 选择应同时考虑**：聚类稳定性、簇间分离、簇内一致性、时间连续性、
**后续细化后的标签稳定性**、在标注开发集上对句子归属率的直接效果。

> **最重要的一句**：**K 应该在最终真实路径上评价，而不是只在离线 2 秒窗候选表上评价。**
> 如果完整细化太慢，可以先用少量候选 K 做真实路径评估、建一个**低成本近似器**，
> 但不能假设离线 silhouette 会自动代表最终效果。

### 1.2 项目负责人给的判据（用于判断"拆门"的去留）

| 观察 | 应对 |
|---|---|
| 拆门在大多数场次有效，且无明显回归 | 保留拆门，作为 v13 基础修复 |
| **拆门效果高度依赖 cohort** | **保留拆门，但加分布条件或不确定状态，不能包装成普适提升** |
| 拆门基本无效，而换评分函数有效 | 主要工作转向 K 判据 |
| 两者都不稳定 | 问题可能已进入 Embedding 可分性 / VAD 覆盖率 / 锚点传播机制，继续调 K 收益有限 |

**当前落在第 2 支**（判定依据见 §5.3）。

### 1.3 物理边界报告要保留

**它不是附属材料。** 单通道天花板、短发言者前端不可见、分离式提纯已被否证，
这些内容能解释**为什么系统不会无限接近 100%**，
也能防止后续**把结构性错误误判成参数问题**。

## 4. v13 的三道串联锁（已修，是 v13 的基础修复）

`claude_a2_v11.py` 的 `_candidate_clusters` + `_select_candidate` 里，
任意一道拦下就把整张 K≥2 候选表废掉，回退 `candidates[0]` = **k=1**：

1. **上限在 def 时绑定**：`_candidate_clusters(E, max_speakers=MAX_SPEAKERS)` 的默认值
   在**定义时**绑定为 v11 常量 **4**（`__defaults__ == (4,)`）。v12 调用时不传该参数，
   所以 v12 自己的 `MAX_SPEAKERS = 10` 与 `_v11_window_params` 的 `setattr` **对它完全无效**。
2. **尺寸门** `min(sizes) >= MIN_CLUSTER_WINDOWS(4)`；
   **份额门** `min(sizes)/n >= MIN_CLUSTER_SHARE(0.015)`。
3. **孤窗**：任一簇 <2 窗 → `_silhouette` 直接返回 **−1.0**；
   `_select_candidate` 末尾还有一道 `best["score"] > 0.0`。

**一个 1 窗的孤立簇可以单独触发锁 1 与锁 3。**

**三道锁互相依赖，单独拆任何一道都是精确的 no-op**（实测：只拆锁 3 = 不变；
只拆尺寸+份额门 = 不变；**三道同时改 = dev 24.9% → 18.3%**）。

**唯一实现**：`scripts/evaluation/unlocked_selector.py`
（`CAP=10` / `MIN_WIN=2` / `build_unlocked` / `pick_unlocked` / `unlocked`）。
不要再去修 `MIN_CLUSTER_SHARE` 单个常量——它单独不改任何东西。

## 6. 下一步（三步，有依赖）

### 第一步：句子级指标的可实现性核查（**便宜，半小时内，先做这个**）

纯统计，不加载模型。量三件事：

1. 20+30 场里**有多少句子能算**（按 TextGrid 非空 `mark` 的区间）；
2. **重叠语音的"弃权"比例**多少（若某句没有任何说话人占 ≥50%）；
3. **<0.5s 极短句的占比**（本项目已知参考里 53 个小说话人中位仅 2.0s）。

**如果弃权比例过高（比如 >20%），指标定义就得改，越早知道越好。**

### 第二步：写句子级指标 + 低成本 K 近似器

**建议的指标定义**（待项目负责人确认）：

| 问题 | 建议 | 理由 |
|---|---|---|
| 句子时间范围 | 参考 TextGrid 的 tier 区间（`mark` 非空段） | "句子"唯一有真值定义的地方；用 ASR 分段会引入 ASR 误差 |
| 重叠语音 | 判给占该句时长**最多**的说话人；若**无任何说话人 ≥50%**，记**弃权**（不计入分母但报出比例） | 目标场景是轮流发言；抢话时"归属"本身无良定义，硬判会造假错误 |
| 短句/极短句 | 主表只算 **≥0.5s**；<0.5s 单列一项 | 极短句噪声大于信号 |
| 平均方式 | **按时长加权**为主表，按句平均为辅表 | 0.6s 的"嗯"与 20s 发言不该同权；两个都报以免偏 |
| 标签置换 | **匈牙利算法**（`scipy.optimize.linear_sum_assignment`）在句级混淆矩阵求全局最优 | 现有 `der()` 用**贪心**映射，句级用全局最优更稳；scipy 已在依赖里 |

> ⚠️ **必须写进报告的两条限定**：
> ① **用 TextGrid 区间当"句子"，而 TextGrid 区间本来就是标注产物**（标注者在停顿处切的），
> 不是客观的语言学句子。这个指标测的是"**标注单位上的归属率**"。
