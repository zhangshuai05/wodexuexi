# c1 v8 里程碑：2026-09-14

v7 三项致命缺陷修复的三态契约 + 外生证据版本，方法标识 `claude-a2-v8-c3`。
本目录是独立归档；v4/v5/v6/v7 与工作区、DSH 测试台的历史文件均保留。

**v8 是新增 lane，不替换 c1。** c1（`claude-a2-v7-c1`）仍是当前双人基线。
理由见"效果"与"结论"。

## v8 变更

三项缺陷的共同形状是**判据的参考量由被判决的对象自己产生**：

| 缺陷 | v7 的自指位置 | v8 修法 |
|---|---|---|
| 1 人数强制为 2 | 段级/窗级各自 `fcluster(t=2)` | 三态 `1 / 2 / uncertain`（`count_gate`） |
| 2 救援门自己当裁判 | 基线与候选同源（`_rescue_gate` 的 `n_sw_win`） | 换外生判据：无静音支撑切换占比 |
| 3 ASR 无契约 | `verdict` 字面常量 | flag 分类 + 三态 verdict |

新增证据层 `claude_a2_v8.py`（纯函数，不加载模型）与 `claude_a2_asr_contract.py`。

关键约束：工作日志 621-623 已实测**三个标准 k 判据在 CAM++ 特征空间全部失效**，
所以 v8 一律不用簇内相似度，只用**外生证据**（VAD 静音结构）与**跨段预测**。

### 1 人／多人三态

`count_gate`：k=2 段级间隙 ≤0.02 → 1 人；k=3 间隙 ≥0.10 **且三簇都像样** →
`uncertain`；否则 2 人。

> 修正记录：首版按 `k3/k2 > 1.5` 判 uncertain，把 6 个真值 2 人文件全误判，
> 其中包括全集合 DER 最好的 `Note20260803112220`（1.9%）。根因是 k3/k2 大
> 只说明"第三簇离得远"。现改判"第三簇本身是不是像样的簇"（真 3 人 k=3 得
> `3/3/3`，真 2 人硬切 k=3 得 `5/4/1`）。

### 救援门外生判据

dense 候选的**无静音支撑切换占比** ≤5% 才采用，否则回退 window。
v7 的切换数基线已被废弃——它拿同模型欠切结果当参考，系统性偏向少切。

### ASR 契约

flag 分两类，混在一起会让"短段没解码"冒充"ASR 幻觉"：
- 覆盖缺口（非幻觉）：`too_short`
- 文本可疑（正是 DeepSeek 看到的幻觉）：`empty` / `too_fast` / `repeated` / `no_speech`

字符速率分母用 **VAD 有声时长**而非段墙钟（否则正常短答"对。"会被算成超速）；
n-gram 重复必须**连续**（"谢谢谢谢"是自然口语，"我们我们我们"才是幻觉循环）。

| 人数判对 | 23/23（恒输出 2） | 23/23（真判定） |

| 语言覆盖 | — | 逐文件不变（如 121.2s → 121.2s） |
| 边界 precision / recall | 83.8% / 33.1% | 83.8% / 33.1% |

**c1 的 23/23 是虚的**：它无条件输出 2，而语料恰好全是 2 人。

**边界数字两行完全相同**的含义：21/23 文件的切换点集合与 c1 **逐一相同**。
v8 段数下降全部来自合并相邻同标签碎段，是碎片清理，不是检测能力提升。

`Note20260803111143` 最直观：GT 24 个话轮切换，**c1 与 v8 都只给 2 个**，
位置完全一致 `(27.0s, 44.1s)`。

## 可分性诊断：瓶颈在前端噪声，不在判决规则

用人工转写（**只用 q=asr 轮**）给窗贴标签，算同人/异人余弦与 EER。

| 分组 | 文件数 | 平均 EER |
|---|---:|---:|
| EER < 20%（可分） | 4 | **中位 5.2%**（1%~10%） |
| EER ≥ 20%（弱） | 10 | 中位 41.2% |
| 标签不足 | 9 | — |

**信息确实在嵌入里**（可分文件 EER 低至 0.7%），所以三条路已用数据否证：

| 已否证的路线 | 证据 |
|---|---|
| 换 SV 模型 | eres2netv2 29.3% vs campplus 29.0%，持平 |
| 调判决规则 | raw 29.0% 已最优；center 33.9%（变差）；ZCA 49.5%（破坏） |
| 调救援门/碎段阈值 | v7 评审 + 本轮：21/23 文件切换点不变 |

分布由**噪声**主导而非距离：安静 21.7% vs 嘈杂 **38.7%**；
按距离无单调关系（1m 组 EER 从 3% 到 49%）。

> 修正记录：4 文件冒烟测试曾得 EER≈47~50%，据此判断"信息不在嵌入里"。
> 全量 23 文件推翻了它——那 4 个恰好是最差的。小样本冒烟不能用来否决路线。

**下一轮主攻方向：前端降噪**（FRCRN 已在本仓库、已用于其他泳道），
针对的正是已量化的"嘈杂 EER 高"。不要换 SV 模型，不要调判决规则。

## 局限

- **3 人以上无真实素材**：23 个真值文件全是 2 人。v8 对 k=3 证据成立时返回
  `uncertain` 而非硬猜，但**这条路径未经真实数据验证**，不声明为已实现能力。
- **单人长录音无真实素材**：无探针（用户场景为多人，故不做合成验收）。
- 嘈杂档自动 GT 漏标率高（`gt_ts_diag` 插值轮占比最高 85%），
  其边界与 DER 结论只作参考。
- v8 净收益为 0：救援门判据正确（能诊断 dense 过切）但回退后产出同 c1。
  v8 的相对价值在**契约与可观测性**（可靠性标记、人数三态、救援门诊断）。
