# 下一阶段方案：先验证多人分离机制，再决定算法升级

## 1. 当前结论与本阶段目标

下一步优先完成“可复现评测＋多人身份分离实验”。保留当前 v7 作为对照，独立实验版本通过验证后，再讨论自动人数和实时会议链路。

本次只读复核确认：

- 30 项测试通过；细化门已经撤销，v10 仍调用 v7 生成说话人标签。
- 三人素材不降噪时，5/5 都输出两个标签并报 `uncertain`，其中 **4 条仅因文本可疑触发**。因此，这次修复改善了风险提示，尚未证明能够识别“漏掉第三个人”。
- 两人限制分布在聚类、双质心细化和标签判决等多处，单改 `CLUST_N` 无法完成多人化。
- FRCRN 的耗时问题已有改善，但微小波形变化会被后续离散判决放大。还需要区分预处理波动、嵌入波动和聚类敏感性。

你提供的“全局 51.9%／B 段单独 86.7%”是重要线索，本阶段将用统一输入和评分口径复核，不直接据此断定唯一根因。

## 2. 如何借鉴论文

这篇 [2018 年综述](C:/Users/EDY/Desktop/new/not_mind/papers/Supervised-Speech-Separation-Overview/Supervised-Speech-Separation-Overview.md:312) 对方案有三个直接启发：

| 论文观点 | 对当前项目的具体用途 |
|---|---|
| 局部片段分得开，还需要跨时间的“序列组织” | 同时检查局部可分性与整段身份一致性，尤其是两场次共有的店员是否保持同一标签 |
| 聚类可表达多个说话人；PIT 输出通道可能发生身份交换 | 多人实验允许任意数量标签；评分必须使用整条录音的一次最优一一映射，不能逐段重新配对掩盖身份漂移 |
| 泛化依赖说话人、噪声和场景覆盖 | 现有拼接素材只作机制验证；来源重用的数据不能作为独立多人泛化证据 |

论文中的深度聚类学习的是**时频单元嵌入**，与当前 CAM++ 语音窗嵌入不同，不能直接套其结论。当前素材没有重叠发言，优先研究身份聚类；PIT、掩蔽分离及已有 MossFormer 模型留作后续真实重叠场景的专项实验。

## 3. 按顺序执行的工作

### 第一步：冻结输入，让对照可重复

- 保存当前代码、模型、配置和真值版本的哈希；将当前 v7 标为“含 verdict 修订的基线”，避免继续用同一方法名混装历史结果。
- 每条素材保留两种固定输入：原始规范化音频、一次生成并冻结的 FRCRN 音频。候选算法必须读取同一份音频。
- 保存对应的 VAD 区间、长窗/密集窗嵌入及时间索引。复用已有缓存思路，缓存键包含输入哈希、模型权重、配置和采样率。
- 分层重复五次：重新运行 FRCRN、固定音频重提特征、固定特征重跑聚类。记录首次分歧发生的位置，以及最终标签和边界变化。
- 实验在独立进程中串行运行，避免共享 `_A2D`、模型释放和其他请求影响对照。

固定特征仍不能重复得到相同结果时，先处理这层不稳定性，暂停效果比较。固定输入只用于控制变量，不能据此宣称线上重复性已经解决。

### 第二步：修正诊断语义和评分口径

保留 verdict 的保守方向，暂不根据报警数量放松阈值，但补齐以下契约：

- 当前“语音占比”其实按输出段跨度计算，而且先丢弃短于 0.3 秒的单段。改为按标签累计与 VAD 相交后的有效语音，去除重复覆盖，再检查累计时长和占比。
- 0.3 秒、10% 暂保留为旧版风险提示参数；低占比只能说明支持不足，不能证明这个人不存在，更不能成为新算法删除少数发言者的规则。
- 区分“聚类假设人数”和“实际输出标签数”。目前 `n_clusters` 来自输出本身，单标签结果未必触发所谓的自相矛盾检查。
- 空输出不能报 `reliable`；`collapsed=True` 只说明初始路径曾塌缩，不能直接写成“救援未恢复第二人”。拒绝救援也不能证明回退结果更差。
- 将原因分为分离风险、文本风险、覆盖缺口，保留兼容的顶层 `verdict`。同时核对批次：当前落盘的 17 条 uncertain 都含文本可疑理由，与“16 条”的记录有出入。
- 删除注释和测试说明中已作废的 5.9pp 对照；用行为测试证明高切换数的有效细化结果不会被段级切换预算拒绝。

评分采用 SciPy 的矩形最优一一匹配，未匹配说话人必须计错。现有评分代码存在少标签时的映射限制，以及按较短输出截断计分的问题，本轮建立独立实验评分入口，不修改 DSH。

合成素材按时间对应评分；`q=gap`、越界截断等不可靠真值单列披露。未标注区域不擅自当静音。报告有效评分覆盖率、漏人、身份混淆、短答归属和跨场次身份一致性。

### 第三步：做最小机制实验，拆开人数与表示问题

所有实验读取同一份冻结特征，不接 ASR 和 LLM。比较下列组合：

| 实验 | 处理方式 | 要回答的问题 |
|---|---|---|
| 基线 | 当前 v7 完整路径 | 当前错误在哪里 |
| 段级表示 | 固定同一套段代表，分别指定 K=2、K=3 | 仅解除两簇限制能改善多少 |
| 长窗表示 | 固定长窗嵌入，分别指定 K=2、K=3 | 段均值是否已经混掉不同身份 |
| 密集窗表示 | 固定密集窗嵌入，分别指定 K=2、K=3 | 更细粒度表示能否保留第三人的证据 |

实验聚类统一采用现有 SciPy 的 average-linkage、cosine 距离；不在不同 K 下切换其他处理策略。

对 0657/1031 及其余四组，同时比较 A 单独、B 单独和 A+B。单独处理时使用整条音频同一次预处理得到的对应区间，避免把 FRCRN 上下文变化误当成聚类变化。

已知拼接位置和已知 K 只用于诊断。增加 A/B 调序及已有双人 selfsplit 对照，检查收益是否仅来自拼接缝或录音场次。局部两簇结果即使很好，也必须通过全局身份对应才能算收益。

### 第四步：产出独立离线实验版本

- 实验入口允许显式指定 K，支持 K=1、2、3、4；这是诊断参数，标记为 `oracle_k`，不能称为自动人数识别。
- 多质心判决使用所有质心的相似度，保留最高与次高得分差；移除实验路径里的二元标签翻转和双质心假设。
- 输出沿用 `sentence_info`、`diag`，方法名独立，`verdict=experimental`，附输入/特征哈希、指定 K、实际输出标签数和处理路径。
- 本阶段不新增生产 HTTP 接口，不把新实验接成 v10 的“升级”，也不同步其他副本。

## 4. 验证与完成标准

必须留下可运行检查：

- 空输出、累计短发言、低占比真实说话人、成功救援后的诊断、VAD 交集及重复区间。
- 三个真人仅输出两个标签时不能被评分美化；预测提前结束仍计漏检；标签编号置换不改变分数，跨场次交换身份应受罚。
- 固定特征重复五次，标签与边界一致。
- FRCRN 短音频、15 秒边界和不足一块的尾部：样本数、有限值和时间对齐正确。另比较真实模型切块前后效果，不能用恒等函数测试证明音质无损。
- 现有 23 条双人、5 条三人、双人 selfsplit 和 04320 短答样例逐条报告。安静与嘈杂、原音与冻结降噪输入分别统计。

本阶段交付：冻结清单、可复现实验入口、逐文件指标表、独立多人实验版本，以及“人数限制／表示混合／数值敏感性各贡献多少”的证据报告。实验判负也是有效结果，不以输出三个编号作为完成证明。
