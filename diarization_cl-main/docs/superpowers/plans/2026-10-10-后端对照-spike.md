  ```

  ⚠️ **两场例外的性质不同，不要混写**：`L_R003S01C02`（15/15/14）是
  **`2==8` 成立而 `8==16` 不成立**（唯一一场 `8==16` 失效）；`S_R004S01C01`（15/13/13）
  是 **2≠8 而 `8==16` 成立**。
  ⇒ 实际只有 **`{2,8,16}` vs `{32}`** 两点差异。**画成 4 点曲线是假象。**
  ⚠️ **可省一半扫描量**：池的类集合相同 ⇒ 窗集合相同 ⇒ `lda_fit` 输入逐位相同
  ⇒ 输出逐位相同。所以 `2/8/16` 在 10/12 场上是**算术恒等**，不是"实测差异很小"。
  产物仍记 4 档原始数字，但**报告时合并成 2 个配置**（`{2,8,16}` / `{32}`）并说明恒等，
  否则读的人会把恒等看成"扫描发现轴很平"。
  ⚠️ 产物必须记 **kept 的类名清单**（不能只记个数）：dev 上 **8/12 场 |S16|=16**。
  本项目这份数据里，**计数相同处集合也相同**（未出现反例）——
  但那是这份数据的性质，不是"计数够用"的证明：`fit_backend` 的输入是
  **类的集合**，计数只是它的一个投影，投影相同不蕴含原像相同。
  类名清单是原像，且可以事后用于**判定两次运行的池是否逐位相同**
  （本计划"可省一半扫描量"那条推论就是靠它成立的）。
  ⚠️ 32 档的完整账（判据是 **S2 与 S32 的差集**，不是 S16 与 S32）：

  | \|S2−S32\| | 场次数 | 谁 | 说明 |
  |---:|---:|---|---|
  | 1 | **9** | `M_R003C01:003-F`（19 窗） | 8 场；`M_R003S05C01` 是 `005-F`（18 窗） |
  | 2 | **2** | 多掉 `L_R003C02:007-M`（25 窗）/ `L_R003C02:002-F`（9 窗） | `L_R003S02C02` / `L_R003S01C02` |
  | 3 | **1** | 再多掉 `S_R004C01:002-F`+`003-F`（各 3 窗） | `S_R004S01C01` |

  ——这解释了为什么它**必须**用 `S2−S32` 而**不能**用 `S16−S32`：
  `L_R003S01C02` 的 `002-F`（9 窗）与 `S_R004S01C01` 的两个 3 窗类
  **在 8/16 档就先被剔掉了**，用 `S16−S32` 看会把它们算成"没动过"，
  于是 12 场看起来"每场只掉 1 个"，而实际是 `9 / 2 / 1`。
  `M_R003S05C01` 同理：排除该场后 `003-F` 只剩 1 窗，**在最低档 2 就出局**，
  轮不到 32 档动手，掉的是 `005-F`。
  ⇒ `classes` 轴在 dev 上**基本无分辨率**，`32` 是唯一真正改变池的档位。

def fit_backend(pool, target, min_class_windows, normalize):
    """用除目标场外的全部纯窗拟合 LDA，类 = (身份组, 说话人)。

    返回 `(fit, kept_names)` —— `kept_names` 是**保留类的名字清单**（已排序），
    不是个数。`classes` 轴的真实分辨率只有两点（见全局约束），
    只有类名清单能让产物自证用了哪批类。
    """
    Xs, ys = [], []
    for meeting, (emb, times, speakers, votes) in pool.items():
        if meeting == target:
            continue
        pe, _, ps = pure_windows(emb, times, speakers, votes)
        if len(pe):
            Xs.append(pe)
            ys.append(np.array([f"{meeting_group(meeting)}:{x}" for x in ps]))
    if not Xs:
        return None, []
    X, y = np.concatenate(Xs), np.concatenate(ys)
    counts = Counter(y.tolist())
    kept_names = sorted(c for c, n in counts.items() if n >= min_class_windows)
    if len(kept_names) < 2:
        return None, []
    fit = lda_fit(X, y, min_class_windows=min_class_windows)
    if fit is None:
        return None, kept_names
    return Transform(fit.mean, fit.weights, normalize=normalize), kept_names

def variants_for(class_limits, norms, k_modes=("true",)):
    """枚举全部变体名。

    命名：`{none|c<类窗下限>_{cos|euc>}[_autok]`

    ⚠️ `_euc` 变体**不进 autok 臂**：`build_unlocked` 内部
    `linkage(E, method="average", metric="cosine")` 是写死的
    （`unlocked_selector.py:48`），而欧氏空间的 LDA 输出必须用欧氏距离。
    让它跑 autok 等于用余弦 silhouette 评价欧氏空间。
    给它加 metric 参数会动到生产共用实现 —— 不值得，跳过即可。
    """
    out = []
    for k_mode in k_modes:
        suffix = "_autok" if k_mode == "auto" else ""
        if k_mode == "auto":
            out.append("none" + suffix)
        elif k_mode == "true":
            out.append("none")
        for c in class_limits:
            for n in norms:
                if k_mode == "auto" and not n:
                    continue
                out.append(f"c{c}_{'cos' if n else 'euc'}{suffix}")
    # 去重保序
    seen, uniq = set(), []
    for v in out:
        if v not in seen:
            seen.add(v)
            uniq.append(v)
    return uniq
```
