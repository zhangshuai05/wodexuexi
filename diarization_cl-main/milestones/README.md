`c1_v8_20260914` 的定位与本表其他版本不同：它**不是**新的部署基线，而是
v7 评审三项缺陷的修复分支（方法标识 `claude-a2-v8-c3`）。c1 仍是双人基线——
v8 在 21/23 文件上切换点与 c1 完全相同，净 DER 略差（18.1%→20.0%）。
v8 的价值在**契约与可观测性**，以及本轮产出的**否证结论**：
可分性瓶颈在前端噪声（安静 EER 21.7% vs 嘈杂 38.7%），
换 SV 模型（eres2netv2 持平）与调判决规则（raw 已最优）均无效。

`c1_v81_20260917` 与前两者又不同：它**改的是 c1 这条路径本身**（不新增 lane），
但**只动 verdict 的算法**，聚类/救援/边界一行未动，方法名仍是 `claude-a2-v7-c1`。
因此**本版的输出段与几何与历史 v7 逐格一致**（安静组 11/11 实测相同），
只有 `verdict` / `verdict_reasons` / `diag.assumed_k` 是新字段。
凡引用"含 verdict 修订的 v7"，以本目录的 `SHA256.json` 为版本标识。

这是代码归档，不含模型、音频、Python 运行时或 FFmpeg 二进制。每个版本内的 `README.md`、`request.txt` 说明复现方法及环境要求。
