# v11 多人聚类实验记录（2026-09-17）

## 目的

v7 固定输出两人，无法处理 `Audio/Merged3Spk/` 的三人音频，也会把同标签的多轮对话
合成一个长 ASR 输入。v11 作为独立实验泳道，不改动 v7/v10 基线。

## 实现

- 方法：`claude-a2-v11-multispeaker`。
- 使用 VAD 覆盖至少 50% 的 0.6 秒 CAM++ 窗，步长 0.15 秒。
- 对同一组窗一次生成 K=1--4 的 average-linkage / cosine AHC 候选；仅接受每簇至少
  4 个窗、且占比至少 1.5% 的候选，再以带轻微 K 惩罚的 silhouette 选择人数。
- 相邻弱孤立窗才允许吸收；输出段不跨 VAD 时间断层；单个 ASR 输入最长 8 秒。
- `v11_eval.py` 只按时间评分：使用可信 GT（`q=asr` 且非 `clamped`）建立一次全局
  Hungarian 一一映射，再固定映射报告全量、可信和低质量时间戳结果。它不读 ASR 文本。
- LLM 现在只能保留输入已有的任意数量标签，不能新增或删掉 speaker；已校正结果不可再次校正。

## 冻结条件

- 输入：`Audio/Merged3Spk/CallMerge_*.wav`，逐条上传至 8735。
- 表中运行参数：`lanes=v11&denoise=off`。关闭 FRCRN 是为了排除已确认的 GPU 数值波动；
  它不是页面默认的自动降噪结果。
- 输出：`output/v11_20260917_CallMerge_*.ndjson`。
- 汇总：`python -B v11_batch_eval.py`。

记录；这正是全局评分器需要保留的失败信号。

## 结论

v11 已解决一个明确的结构性问题：它会把每次 ASR 输入限制在 8 秒以内，避免将开头二十多秒的
混合轮次直接送进单次 ASR。自动人数模式在 1423/1842 与 1506/1938 上完整找回三人，并维持
共享店员的跨场次身份。

自动人数尚未解决嘈杂素材的通用多人识别：0228/0836 仍选一人，0454/0948 仍选两人，0657
虽输出三人但严格一一映射失败。固定 K=3 的内部诊断在 0228 自动降噪输入上只得到约 1 秒的
短片段标签，不能代表第三人，因此不暴露在前端。v11 保持 `experimental`，不替换 v7，也不作为
真实多人会议能力的验收结论。

自动降噪输入在本记录生成前不能横向比较：同一 0228/0836 连跑时，FRCRN 的微小波形差异会让
v11 从 K=2 漂到 K=1。8735 现已将每份规范化输入的首次 FRCRN 输出按输入哈希冻结并复用；
后续自动降噪对照必须记录该哈希，历史自动降噪读数不与本表混合。

## 自动降噪复现校正

2026-09-17 对 `CallMerge_0228_0836.wav` 的两次连续请求使用相同参数：
`lanes=v7,v11&denoise=auto`。首次生成的规范化输入哈希为
`6699138f1f1ebe98b4ae347d9a9f981833ee4ea3a0efff5c9ce52ab3a7ae22a6`，冻结 FRCRN
输出 SHA256 为 `ecb2c435d2c038aad45761b6d5727aa38ed72eedd9035d1947c739e29bc5a29e`。

第二次请求命中同一缓存，v7 和 v11 的 `(start, end, spk)` 序列均逐条一致：

| 泳道 | 首次 / 二次缓存命中 | 输出标签 | 结论 |
| --- | --- | --- | --- |
| v7 | false / true | 0, 1（54 段中 53 段为 0） | 双人基线仍严重塌缩 |
| v11 自动人数 | false / true | 0 | 自动 K=1；未识别多人 |

此前为已知三人音频临时暴露的固定 K=3 诊断，在同一自动降噪输入上只得到约 1 秒的第三标签，
内容主要是短填充词和空文本，不能当作第三人证据，已不再显示在前端。v11 自动模式在这条嘈杂
输入上仍失败；冻结缓存只保证该失败可以稳定复现。

对同一冻结输入的局部 VAD 块诊断进一步表明，`138.6–139.95s` 附近可见拼接处的 1.35 秒
断层，但后半 `145.5–205.5s` 的 376 个 CAM++ 窗仅支持 K=1；前半 `41.1–113.7s` 的 443 个窗
支持 K=2。因此当前失败不是“忘了允许第三标签”，而是后半两个真人在现有 CAM++ 表示中没有
形成两个受支持的簇。下一轮需要比较新的声纹表示或有声学依据的局部 turn 证据，不能靠降低
K=3 支持阈值或强制输出 `speaker_2`。
