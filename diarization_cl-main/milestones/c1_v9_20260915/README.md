# c1 v9 里程碑：2026-09-15

v8 的三项缺陷**复核结论**之上的修正版，方法标识 `claude-a2-v9-c3`。
本目录是独立归档；v4/v5/v6/v7/v8 与工作区、DSH 测试台的历史文件均保留。

## 先更正 v8 的自我定位

v8 被标为"三项致命缺陷修复版"。逐行复核（2026-09-15）后，这个标记不成立，
准确说法是：**v8 增加了诊断字段，三个结构问题都没有闭环**。三处最具体的：

| # | v8 声称 | 代码事实 |
|---|---|---|
| 1 | 证据层"一律不依赖 CAM++ 嵌入" | `count_gate` 的主判据是 `fit_multi_k`，**输入就是 CAM++ 段质心**；完全外生的只有 `run_stats`，而它的 `unsupported_ratio` 只生成理由字符串、不参与任何分支 |
| 2 | 救援门改用外生判据 | `unsupported_ratio` 在 `n_sw=0` 时返回 0.0，"一个切点都不给"能拿满分；门只惩罚切得脏，不惩罚切得少 |
| 3 | ASR 契约把 reliable 变成算出来的量 | `too_short` 不进 `SUSPECT` 也不触发降级；`MIN_CHARS_PER_SEC` 定义后从未使用；顶层 `if not flags` 只加理由不改返回值 |

三条都可复现（v9 测试里逐条钉死）。另外 v8 的"人数判对 23/23"是**训练集成绩**：
阈值在这 23 个双人文件上出现 6 个误判后调整，再用同一批报 23/23，没有留出集。

## v9 改了什么

### 1 救援门补欠切下界（缺陷 2，已闭环）

`PURE_RESCUE_MIN_SW = 2`：dense 候选切换数低于此即回退 window，不再让"零切换"
拿 `unsupported_ratio = 0.0` 的满分。上界 `PURE_RESCUE_MAX = 0.05` 保持。

> 仍**未修**的部分：`min_pause=0.15 / min_run=0.75` 双条件把连续交接、抢话、
> 重叠语音和短答一律判成"无静音支撑"。这个指标衡量的是部分过切，对漏切只有
> 上面这条下界在管。c1 与 v9 的边界 recall 都是 33.1%——本版没有提高召回，
> 不要按"边界问题已修复"解读。

### 2 单人输出按 VAD run 切开（缺陷 1 的下游）

v8 判单人后返回 `(首段起, 尾段止, 0)` 的一个整段，把中间所有静音一起吞掉，
`ASR` 拿到的是跨静音的焊接段。改成 `_single_runs`：按 VAD 有声 run 输出，
相邻 run 间隔 <0.3s 才合并。

### 3 ASR 契约真的会降级（缺陷 3，已闭环）

`_verdict_from` 增加两条通道，且速率下限接进了判定：
- **覆盖率**：`file_coverage = 字符数 / VAD 有声总时长`，低于 `min_cps=0.8` →
  `uncertain`。分母优先用有声时长（用墙钟会把大段沉默的正常文件算成覆盖不足）。
- **零解码兜底**：`flags` 里没有任何 `ok` → `uncertain`。这是"20 段全部未解码
  仍 reliable"的直接成因。只在这一个条件下触发，夹带短段的正常文件不受影响。

`MIN_CHARS_PER_SEC` 从死变量变成实际判据。段级仍**不**判低速率——中文短答
"对。""好。"只有一两个字，段级判会把真值文件全打成可疑。

### 4 文档改为如实记录（缺陷 1 的声明部分）

`claude_a2_v8.py` 模块 docstring 把证据按外生性分成三档（完全外生 / 半外生 /
非外生），不再笼统声称"一律不依赖 CAM++"；`count_gate` docstring 直接标注
主判据非外生，并在返回的理由里显式写出 `[诊断] 无静音支撑切换 x/y（未参与判定）`
——让"它没进决策"成为可机检的事实。

## 未闭环：人数三态仍由嵌入间隙决定（待决策）

`count_gate` 的 1 人 / 2 人分支走 `fit_multi_k`（CAM++ 段质心），v9 **没有改**。
两种改法方向相反，需要人来选，故本版停在这里：

- **A 让它进决策**：把 `unsupported_ratio` 之类的外生量接进 1/2 人的分支。
  逻辑自洽，但会重排现有 23/23，等于宣布那批成绩作废，必须重跑全量。
- **B 保持只作诊断**：v9 现在走的就是这条（改文档、加诊断，不动行为），
  代价是"人数问题已修复"这句必须继续撤回。

挑选 A 之前，`ISO_GAP / gap_multi_abs` 这些阈值也必须在留出集上重定，
否则换汤不换药。

## 效果

**本版没有跑全量 23 文件重测**，因此不给 DER / 边界数字——上面几处改动会改变
判单人的文件（输出段数上升）和 verdict 分布，用 v8 的数字冒充实测是不诚实的。
已有的可复现结论：

| 检查 | v8 | v9 |
|---|---|---|
| 无语音段 verdict | `reliable` | **`uncertain`** |
| 20 段全 `too_short` | `reliable` | **`uncertain`** |
| 100s 有声识别出 1 字 | `reliable` | **`uncertain`** |
| 常态文本 verdict | `reliable` | `reliable`（不变） |
| 判单人后的段 | 1 个跨静音整段 | 按有声 run 切分 |
| dense 零切换候选 | 通过门 | **回退 window** |
| 单测 | 15 项（0 项覆盖 ASR 契约） | 27 项（9 项覆盖契约） |
